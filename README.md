# numbertheoryMCS

**微型汉语系统（Micro Chinese System, MCS）的数论自动证明实现。**

基于 Cheng (2012)《微型汉语系统的构建》与 Cheng (2019)《认知发展理论》第 8 章「形式运算」的工程实现，用「概念三角形 + 递归点火 + 同构迁移 + solidify」做自动定理证明。

## 当前版本：20.8 — Erdős–Straus 猜想的 S-单位方程归约

类 | 比例 | 证明方式
---|---|---
p ≡ 3 (mod 4) | 50% | 经典恒等式（19.0.3）
p ≡ 5 (mod 12) | 25% | 经典恒等式（19.0.4）
p ≡ 13 (mod 24) | 12.5% | 经典恒等式（19.0.5）
**合计** | **87.5%** | **符号证明**
| p ≡ 1 (mod 24) | 12.5% | **归约为 S-单位方程（20.8）** |

**20.8 核心结论**：
- 对于 \(p \equiv 1 \pmod{24}\)，分支 \(4/p = 4/(p+r) + r/(pq)\) 成功当且仅当 \(r \mid p+1\) 或 \(r \mid p+4\)。
- 若存在反例，则 \(p+1\) 和 \(p+4\) 只能由 \(1 \pmod 4\) 的素因子构成，导出 S-单位方程 \(u_2 - 2u_1 = 3\)（其中 \(u_1, u_2\) 是纯 \(1 \pmod 4\) 平滑数）。
- 该归约已在 MCS 系统中通过 8 个概念神经元逐步推导并固化（见 `theorems/20_8_proof_neurons.json` 和 `theorems/20_8_proof_log.txt`）。

**诚实边界**：该归约将猜想等价于 S-单位方程无解。证明该方程无解需要超越数论（Baker 定理），这是当前数学的边界，MCS 尚未能跨越。

**诚实边界**：87.5% 是复现 Mordell 1969 归约已覆盖的类，不是首次覆盖，不是世界纪录。`p ≡ 1 (mod 24)` 的 12.5% 仍开放（19.0.6 探测对 p ≤ 10^4 数值验证 143/143，但 `d` 无统一符号表达式，不是证明）。
**诚实边界（20.0）**：
- `F_r` 由实际 `p` 枚举（`p_max=100000`），**不**基于二次特征假设。
- 大筛法密度上界引用 Gallagher，**不声称例外集为空**，**不声称乘积严格趋于 0 对所有 `r` 成立**。
- 前 4 个 `r` 的失败率乘积 ≈ 0.1034 < 0.15，趋势递减，但尚未“证明”密度 0。
**诚实边界（20.3）**：
- 实测 `F_r` 已扩展到 `r ≤ 200` 的 23 个素数（`p_max=100000` 覆盖所有非零类）。
- 实测失败率乘积 = **0.018872**，趋势递减。
- `p ≤ 100000` 范围内，23 个分支联合覆盖后，未覆盖素数列表为空。
- 仍**不声称**乘积严格趋于 0 对所有 `r` 成立，**不声称**例外集为空。`68209` 的例子说明，分支扩展会吃掉局部漏洞，但更大范围内可能出现新漏洞。

## 核心能力

- **图式层**：概念三角形（A+B→C）直接点火，200/200 竞赛题 100% 命中，fallback 0，suspect 0
- **递归点火**：上层概念逐层递归（`@0-@0` → `@0-@1`）
- **同构迁移**：跨谓词图式迁移（`divides` ↔ `congruent`）
- **深递归 + 子目标分解**：`DeepRecursiveProver`，能量预算 `E = 2^(N-1)·δ`
- **多域架构**：数论 + Dirichlet 特征 + 椭圆曲线
- **自动学习**：`discover` + `judge` + `commit`
- **证明固化**：`solidify` 把成功路径固化成新神经元
- **假阳性防御**：`Prover` substitution 一致性 + `GuardedProver`（T004/T005 抑制）
